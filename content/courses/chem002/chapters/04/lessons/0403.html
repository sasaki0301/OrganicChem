Naming Alkanes

Follow the carbon connections, find the parent chain, and build an IUPAC name one decision at a time.

1. Start with the parent chain

In this lesson, we name acyclic alkanes: open-chain hydrocarbons with only single bonds. Their molecular formula is CnH2n+2. Rings require different rules and are outside this lesson.

The name of the parent tells us the number of carbon atoms in the chosen continuous chain. The ending -ane identifies the saturated hydrocarbon.

Quick check

What is the parent name for a continuous chain of seven carbon atoms?

Show answer and explanation
Heptane: seven carbon atoms correspond to hept-, followed by -ane.

2. A reliable naming workflow

  1. Find the parent. Trace the longest continuous carbon chain, even if it bends. For equal-length chains in these simple examples, choose the one with more substituents.
  2. Number the parent. Compare substituent locants from each end in increasing order. Choose the lower number at the first point of difference. Compare the complete sets; do not simply add them.
  3. Identify and locate branches. Name each group not included in the parent, such as methyl or ethyl, and record its attachment carbon.
  4. Group repeated branches. Use di-, tri-, or tetra- and give a locant for every branch, even when two share a carbon.
  5. Assemble and check. List different substituent names alphabetically, ignoring di-, tri-, and tetra- for this alphabetization. Use commas between numbers and hyphens between numbers and words. Add the parent name as part of one word.
If locant sets tie completely: for the simple alkyl substituents here, assign the lower locant to the substituent that comes first alphabetically. Alphabetical order does not override a lower locant set.

Compare the whole set

Compare 2,3,5 and 2,4,5. The first locants tie; the second are 3 and 4. Choose 2,3,5 at the first difference.

When comparing directions, sort locants as sets first; retain the connection between each number and its substituent when writing the final name.

Scope: these rules cover the simple open-chain hydrocarbons used here. Competing functional groups, rings, complex substituents, and stereochemistry require additional nomenclature rules.

3. Worked examples: structure to name

Each example pairs a condensed formula with a semi-displayed structural formula. The diagram shows every carbon–carbon bond; hydrogens are grouped as CH₃, CH₂, or CH. Each pair represents the same connectivity.

Example 1 · One branch

Trace, number, and name

CH₃–CH(CH₃)–CH₂–CH₂–CH₃

  1. Parent: five connected carbons → pentane.
  2. Number: the branch is at 2 from the left or 4 from the right; choose 2.
  3. Branch: the remaining CH₃ is methyl.
  4. Result: 2-methylpentane.
Example 2 · Repeated branches

Two groups on the same carbon

CH₃–C(CH₃)₂–CH₂–CH₃

The longest chain has four carbons: butane. Both methyl groups attach to C-2. Give each its own locant and combine with di-: 2,2-dimethylbutane. The full molecule contains six carbons: four in the parent and two in the branches.

Example 3 · Different branches

Number first, alphabetize afterward

CH₃–CH(CH₃)–CH(CH₂CH₃)–CH₂–CH₂–CH₃

  1. A longest chain has six carbons: hexane. Among equally long chains, the chain shown gives two substituents.
  2. From the left, the locants are 2,3; from the right they are 4,5. Choose 2,3.
  3. The branches are 2-methyl and 3-ethyl.
  4. Ethyl precedes methyl alphabetically: 3-ethyl-2-methylhexane.
Example 4 · Equal locant sets

Use alphabetical order to break a numbering tie

CH₃CH₂CH(CH₂CH₃)CH₂CH(CH₃)CH₂CH₃

The longest parent has seven carbons, with an ethyl and a methyl group. Either direction gives the locant set 3,5. Assign 3 to ethyl, which precedes methyl alphabetically: 3-ethyl-5-methylheptane.

4. Read a skeletal formula

Every unlabeled line end and corner represents a carbon atom. Carbon-bound hydrogens are omitted; add enough for each carbon to have four bonds. To name the compound, trace a continuous path of carbons before identifying the leftover branches.

There are five carbons in the numbered parent and one at the extra upper end. The upper end is a methyl branch at C-2. This is another representation of 2-methylpentane.

A frequent trap: A line that looks like a branch can be part of the longest chain. For CH₃CH₂CH₂CH₂CH₃, count all five connected carbons: the name is pentane, not 1-methylbutane.

5. Work backward: name to structure

Draw 3-ethyl-2-methylpentane

  1. Draw five connected carbon atoms for the pentane parent.
  2. Attach a methyl group to C-2 and an ethyl group to C-3.
  3. Add hydrogens so every carbon has four bonds.
  4. Trace the chains again and check that the longest contains five carbons; then compare numbering from both ends.

CH₃–CH(CH₃)–CH(CH₂CH₃)–CH₂–CH₃

The name describes how groups connect, so an equivalent drawing may face a different direction. Here the molecule has eight carbons in total.

Try it yourself

Draw 2,3-dimethylpentane. How many carbons are in the whole molecule?

Show one solution
CH₃–CH(CH₃)–CH(CH₃)–CH₂–CH₃. The five-carbon parent and two methyl groups give seven carbons total.

7. Final checklist

  • Trace the longest eligible continuous carbon chain; a chain may bend.
  • Compare all substituent locants at their first difference.
  • Give every branch a locant; use di-, tri-, or tetra- for repetitions.
  • Alphabetize the simple substituent names, ignoring multiplying prefixes.
  • Use commas and hyphens correctly, and redraw the name to check.

Key terms: a parent chain supplies the base name; a substituent is a group attached to it; a locant is its position number.
