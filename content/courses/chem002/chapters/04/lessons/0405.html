Naming Cycloalkanes: Advanced Practice

Apply ring naming rules to increasingly challenging structures. Compare each structural drawing with its skeletal equivalent before naming it.

Key reminders10 problemsExtension

1. A quick naming checklist

  1. Identify the parent ring or chain. In these simple examples, the ring is the parent when it has at least as many carbons as the attached chain.
  2. Name each substituent; count every branch or heteroatom. Halogens are named with prefixes such as bromo and chloro.
  3. Compare locant sets from possible starting points and directions at the first difference. The lowest set wins before alphabetical tie-breaking.
  4. If the complete sets tie, assign the lower locant to the substituent cited first alphabetically. List substituents alphabetically in the final name.
  5. Use one locant for every repeated group. Ignore di-, tri-, and tetra- for alphabetical order. For common names, iso counts in alphabetical order; the separate prefixes sec- and tert- do not.
Scope: These exercises emphasize connectivity in simple monocyclic compounds. Plain lines do not specify whether substituents are cis or trans; do not infer stereochemistry without additional information. A single substituent on a simple ring does not need locant 1.

In each pair, the semi-displayed drawing shows C–C bonds with hydrogen grouped as CH, CH₂, or CH₃. In the skeletal version, unlabeled vertices and line ends are carbons, and carbon-bound hydrogens are omitted. Labeled Br and Cl are halogens, not carbons.

Problem 4

Name the structure shown. Both drawings represent the same connectivity.

Show answer and reasoning
1-isopropyl-3-methylcyclohexane

Using the common prefix isopropyl, alphabetize under i; the lowest set is 1,3 and isopropyl gets 1. A systematic alternative is 1-methyl-3-(propan-2-yl)cyclohexane; its numbering changes with the substituent names used.

Problem 5

Name the structure shown. Both drawings represent the same connectivity.

Show answer and reasoning
1-tert-butyl-2-methylcyclopentane

The common prefix tert-butyl is alphabetized under b, ignoring tert-. Thus it gets 1 when the 1,2 set ties. This is common-name nomenclature; systematic substituent names use their own alphabetization rules.

Problem 6

Name the structure shown. Both drawings represent the same connectivity.

Show answer and reasoning
1-ethyl-2,4-dimethylcyclohexane

The lowest locants are 1,2,4. Starting at an adjacent methyl and numbering toward ethyl gives 1,2,5, so 1,2,4 wins at the third locant; ethyl is at 1.

The ring has five carbons and the attached straight chain has three, so cyclopentane is the parent. A lone substituent needs no ring locant.

Both directions can produce the 1,2,3 set. Bromo precedes chloro and methyl alphabetically, so it receives 1; list the substituents alphabetically in the name.

3. Extension: when the ring is a substituent

Draw a four-carbon straight chain with a cyclopropane ring attached at its end. Which part is the parent, and what is its name?

Show answer and explanation

The chain contains four carbons and the ring contains three. The parent is butane; the attached ring is cyclopropyl. The name is 1-cyclopropylbutane.

The 1 here locates the cyclopropyl group on the open chain. It is necessary; it is different from the implicit 1 in a monosubstituted parent ring.

4. Self-check before the quiz

  • Compare locant sets before using alphabetical order.
  • On the same ring carbon, repeat its locant for each substituent.
  • Keep each locant with the correct substituent when ordering the name.
  • Check the parent and remember that a skeletal polygon shows connectivity, not necessarily a planar ring.
  • Add cis/trans only when stereochemical information is supplied.
