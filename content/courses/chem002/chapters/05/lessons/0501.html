Naming Alkenes

Learn to identify the double bond, select the parent chain, and name simple branched alkenes step by step.

1. What makes an alkene?

An alkene is a hydrocarbon containing at least one carbon–carbon double bond, C=C. A C=C has one sigma bond and one pi bond; an alkene is unsaturated.

Ethene: the simplest alkene

CH₂=CH₂   ·   C₂H₄

The two parallel lines show the double bond. The semi-displayed formula groups hydrogen atoms with each carbon; in the skeletal formula the unlabeled ends are carbon atoms and carbon-bound hydrogens are implied.

For an acyclic hydrocarbon with exactly one C=C and no other multiple bonds, the formula is CnH2n. For example, but-1-ene is C₄H₈. This formula also fits saturated monocyclic hydrocarbons, so it does not identify a structure by itself. Extra rings or multiple bonds change the formula.

Scope: this lesson names simple open-chain hydrocarbons with one C=C and alkyl substituents. Multiple double bonds, rings and higher-priority functional groups require additional parent-selection and naming rules.

2. A naming workflow

  1. Select the parent. For these one-double-bond examples, choose the longest continuous carbon chain containing both carbons of C=C. A longer chain that excludes the double bond is not the parent.
  2. Number the parent. Start from the end that gives the double bond the lower locant. The locant is the lower number of the two double-bond carbons.
  3. Resolve a tie. If the double-bond locant is the same from both ends, choose the direction giving substituents the lowest locant set at the first difference.
  4. Name branches. Identify and number substituents; use di-, tri-, and so on for repeated identical groups. Alphabetize different simple substituent names, ignoring those multiplying prefixes.
  5. Assemble and check. Use the parent root and -ene, placing the double-bond locant immediately before -ene: but-1-ene. Use commas between numbers and hyphens between numbers and words.
When no position can vary, the locant can be omitted: propene is equivalent to prop-1-ene. The older form 2-butene is common; but-2-ene places the locant next to the suffix.

3. Worked examples: structure to name

Example 1 · Number the double bond

Four carbons, one terminal C=C

CH₂=CH–CH₂–CH₃

  1. The parent has four carbons and contains C=C → butene.
  2. Number from the end nearest C=C: the bond is between C-1 and C-2. From the other end it would be between C-3 and C-4.
  3. Use the lower carbon number: but-1-ene. “But-3-ene” describes the same connectivity numbered from the wrong end; it is not but-2-ene.
Example 2 · Double bond before branch

CH₂=CH–CH(CH₃)–CH₃

  1. The parent chain containing C=C has four carbons.
  2. From the double-bond end, C=C starts at 1 and the methyl is at 3.
  3. 3-methylbut-1-ene. Numbering to give methyl 2 would give the double bond 3, so it is not preferred.
Example 3 · When the double-bond locant ties

CH₃–CH=C(CH₃)–CH₃

  1. The C=C is between C-2 and C-3 from either end → but-2-ene.
  2. Break the tie by giving methyl the lower locant: 2 rather than 3.
  3. 2-methylbut-2-ene.
Example 4 · Follow the C=C, even when the chain bends

Select an eligible parent

CH₂=C(CH₂CH₃)–CH₂–CH₂–CH₃

  1. A six-carbon path can be traced from the ethyl end through the junction and out the other side, but that path omits the terminal C=C.
  2. The longest path containing both double-bond carbons has five carbons → pent-1-ene. It runs from the terminal CH₂ through C=C and toward the three-carbon side.
  3. The remaining two-carbon group is ethyl at C-2. The name is 2-ethylpent-1-ene.

The skeletal lines show carbon connections; the numbered or visually straight route is not automatically the parent.

4. Work backward: name to structure

Draw pent-2-ene

  1. Draw a chain of five carbons.
  2. Place a double bond between C-2 and C-3.
  3. Add hydrogens so each carbon has four bonds.

CH₃–CH=CH–CH₂–CH₃

The name and condensed formula give connectivity; they do not by themselves specify an E/Z isomer. Stereochemical naming needs additional information and rules.

Checkpoint · Read the locant

In hex-2-ene, which two carbons share the double bond?

Show answer
C-2 and C-3. The locant is the lower-numbered carbon of the double bond.

Challenge · Correct the reasoning

A student calls CH₃CH₂CH=CH₂ “but-3-ene” because the formula was written from left to right. Explain the correction.

Show answer and explanation
Number from the right, the end nearest the double bond. The C=C begins at carbon 1, so the correct name is but-1-ene.

6. Key takeaways

  • Alkenes contain C=C; CnH2n applies to acyclic hydrocarbons with one C=C and no other multiple bonds.
  • For these examples, the parent must contain both carbons of C=C.
  • Give the double bond the lower locant before considering substituent locants.
  • If the double-bond locant ties, compare substituent locant sets.
  • Plain connectivity names need not specify E/Z stereochemistry.
